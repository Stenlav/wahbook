# Библиотека Ереси

Каталог книг Warhammer 40,000 — пока только **Ересь Хоруса** — со сгруппированными сериями
(основная серия, Осада Терры, примархи, персонажи, Очищение, повести, книги вне основного цикла), обложками, поиском, фильтрами (тип, статус, автор, перевод) и сортировкой (по порядку серии, году, оценке, названию, автору)
и личными отметками «хочу / читаю / прочитано».

Сайт — это статика на GitHub Pages, которую собирает программа на Go. Отметки пользователя хранятся
в браузере; заготовка бэкенда для аккаунтов лежит в репозитории, но пока выключена.

## Быстрый старт

Нужен Go (см. `go.mod`).

```bash
go run ./cmd/site -serve :8000     # собрать и открыть http://localhost:8000
go test ./...                      # тесты
```

С аккаунтами локально (два терминала):

```bash
ALLOWED_ORIGIN=http://localhost:8000 go run ./cmd/api
go run ./cmd/site -api http://localhost:8080 -serve :8000
```

## Устройство

```
data/books.yaml        каталог: серии и книги (единственный источник правды)
data/annotations.yaml  аннотации к книгам (с FantLab)
data/authors.yaml      русское написание имён авторов и составителей
data/ratings.json      снимок оценок FantLab
assets/covers/<id>.jpg обложки; нет файла — на сайте рисуется заглушка
cmd/site               генератор статического сайта  → dist/
cmd/covers             докачивает недостающие обложки из Open Library (запасной вариант)
cmd/ratings            снимок оценок FantLab → data/ratings.json
cmd/translations       снимок изданий на русском (FantLab) → data/translations.json
cmd/annotations        аннотации FantLab → data/annotations.yaml
cmd/api                бэкенд аккаунтов (отложен, на сайте выключен)
internal/catalog       загрузка и валидация каталога
internal/site          рендер html/template → dist/
internal/auth          пользователи, argon2id, сессии, хранилище (интерфейс Store)
internal/api           HTTP-слой: /api/register, /login, /logout, /me, /progress
web/                   шаблоны, CSS, JS (встраиваются в бинарник через go:embed)
```

### Как добавить или поправить книгу

Отредактируйте `data/books.yaml` (формат описан в шапке файла) и, если нужна обложка,
положите `assets/covers/<id>.jpg` вручную или запустите `go run ./cmd/covers`.
`id` — это slug названия (`Horus Rising` → `horus-rising`). Каталог валидируется при сборке
и в тестах: неизвестная серия, дубликат id или неверный тип — ошибка.

Добавить новую серию (или вселенную) — значит добавить блок в `series:` и книги с этим `series`.

### Где хранятся отметки пользователя

Пока без регистрации и базы данных: отметки «хочу / читаю / прочитано» живут в браузере.
Чтобы они продержались как можно дольше:

- запись идёт сразу в два хранилища — `localStorage` и IndexedDB; если браузер очистит одно,
  при следующем открытии данные восстановятся из другого;
- после первой отметки сайт просит браузер не вытеснять его данные (`navigator.storage.persist()`);
- кнопки **«Сохранить копию» / «Загрузить копию»** выгружают и загружают отметки файлом JSON —
  единственная защита от ручной очистки данных браузера и от автоочистки в Safari (через 7 дней без визитов);
  копию же можно перенести на другое устройство.

### Рейтинги и ссылки

- Средняя оценка берётся с [FantLab](https://fantlab.ru) и хранится снимком в `data/ratings.json`.
  Обновить: `go run ./cmd/ratings` (все книги) или `go run ./cmd/ratings -missing` (только недостающие).
  Если книга не нашлась по названию, укажите `fantlab: <id>` в `data/books.yaml`
  (число из адреса `https://fantlab.ru/work<id>`). Оценка показывается, если голосов не меньше 5.
- В карточке книги оценка — ссылка на страницу книги на FantLab. Поле `wiki:` в `data/books.yaml`
  — страница русской вики, откуда брались сведения; на сайте оно не показывается.

Под названием каждой серии показана её средняя оценка: простое среднее оценок книг серии, у которых
достаточно голосов; рядом указано, сколько книг учтено («оценено книг: 4 из 6»).

### Имена авторов

На карточке имя автора идёт по-русски, под ним — оригинальное написание (как у названий книг).
Соответствия лежат в `data/authors.yaml`; для нового автора в `data/books.yaml` нужно добавить сюда
строку — иначе сборка и тесты упадут. Поиск находит книги по обоим написаниям.

### Звания и достижения

За отметки «Прочитано» даются **звания** (Неофит → … → Примарх) и **достижения** трёх уровней
(бронза, серебро, золото): за серии, авторов, форматы, оценки, годы выхода, «привычки»,
линии героев и несколько секретных. Окно открывается кнопкой в шапке; о новом достижении
сообщает короткое уведомление.

- Правила — в `data/achievements.yaml` (формат описан в шапке файла). Достижение добавляется одной записью;
  «Полное собрание» по каждому автору с тремя и более книгами создаётся автоматически.
- При сборке Go (`internal/achievements`) превращает правила в списки книг и пороги и проверяет их:
  неизвестная книга, недостижимый уровень или неверный порядок уровней останавливают сборку, а не ломают страницу.
  Если файла правил нет, раздел достижений просто не появляется.
- В браузере остаётся только подсчёт отмеченных книг. Полученные уровни и звания **не пропадают**, даже если
  отметки потом сняли; даты получения лежат в тех же двух хранилищах, что и отметки, и входят в «Сохранить копию».
- Достижения по оценкам считаются по снимку `data/ratings.json`; после его обновления набор книг в них может измениться.

### Перевод на русский

У каждой книги есть пометка, существует ли она по-русски, и фильтр «Перевод»:

- **На русском** — есть официальное издание (в подсказке издательство, год и переводчик);
- **Самиздат** — официального издания нет, русский текст есть только в самиздате или любительском переводе;
- **Нет перевода**.

Данные берутся из изданий и переводов на FantLab и хранятся снимком в `data/translations.json`.
Обновить: `go run ./cmd/translations` (все книги) или `go run ./cmd/translations -missing` (только недостающие).
Для книг, которых нет на FantLab (или где он ошибается), статус задаётся вручную полем `translation:`
(`published`, `fan` или `none`) в `data/books.yaml`: оно главнее снимка. Тест проверяет, что у каждой книги статус определён.

### Аннотации

Аннотации — официальные, с [FantLab](https://fantlab.ru), дословно: `data/annotations.yaml` создаёт
команда `go run ./cmd/annotations` (после `go run ./cmd/ratings`, который находит книги на FantLab).
Меняются только переводы строк. Руками файл лучше не править — правки пропадут при обновлении.
Если у книги на FantLab нет аннотации (или самой книги), её можно написать вручную в `data/annotations_extra.yaml`:
этот файл команда не трогает и он главнее сгенерированного. Нет текста нигде — блок в карточке не показывается.

### Аккаунты (отложены)

Серверная часть регистрации уже написана, но на сайте выключена и пока не нужна: `cmd/api`,
`internal/auth`, `internal/api` (argon2id, сессии, синхронизация отметок, тесты). Кнопка «Войти»
появляется только если собрать сайт с `-api <адрес>`; по умолчанию её нет. Когда понадобится,
рекомендуемый путь — вход через внешних провайдеров (Discord/Google/GitHub) и SQLite/Postgres
за интерфейсом `auth.Store`. Если аккаунты не планируются, эти три пакета можно удалить.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте туда проект:
   ```bash
   git init -b master
   git add .
   git commit -m "Библиотека Ереси"
   git remote add origin git@github.com:<пользователь>/<репозиторий>.git
   git push -u origin master
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` сам прогонит тесты, соберёт сайт и опубликует его.
   Адрес: `https://<пользователь>.github.io/<репозиторий>/`.
   (Для репозитория `<пользователь>.github.io` сайт будет в корне домена — путь определяется автоматически.)
4. Аккаунты (сейчас не нужны, пропустите): задеплойте `cmd/api` на любой хостинг с Go или Docker
   (Fly.io, Railway, VPS), задайте `ALLOWED_ORIGIN=https://<пользователь>.github.io`,
   затем в репозитории **Settings → Secrets and variables → Actions → Variables** добавьте
   переменную `WAHBOOK_API` с адресом API — следующая сборка включит вход на сайте.

## Источники и права

Список серий, названия, авторы и даты сверены с русской вики
([Warhammer 40k Wiki, ru](https://warhammer40k.fandom.com/ru/wiki/Ересь_Хоруса_(серия))) и Wikipedia.
Русские обложки и русские названия взяты оттуда же (для непереведённых книг вики показывает
оригинальные обложки с русскими названиями). Обложка «Гнев Терры» пока отсутствует — на вики нет страницы.
Обложки принадлежат правообладателям (Games Workshop / Black Library);
это неофициальный фан-проект, в подвале сайта есть соответствующая оговорка.
